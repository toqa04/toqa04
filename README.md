## 🚀 Featured Missions

### 🐾 Mission 01 · PetNexus — Pet Healthcare Platform

> A platform connecting pet owners with veterinarians and veterinary clinics.

- RESTful API built with **Java** and **Spring Boot**
- Authentication and authorization with **Spring Security** and **JWT**
- Relational database integration
- Real-time messaging between pet owners and veterinary professionals

`Java` `Spring Boot` `Spring Security` `JWT` `REST API`

<br/>

### 🏗️ Mission 02 · Task Management System

> A task management application built around maintainable architecture and separation of concerns.

- **Clean Architecture** and **Domain-Driven Design** principles
- Business logic fully decoupled from the presentation layer
- **MySQL** integration
- **Docker**-based service setup

`Java` `Clean Architecture` `DDD` `MySQL` `Docker`

<br/>

### 🧪 Mission 03 · Java Selenium Automation Framework

> A reusable, scalable UI automation framework.

- **Page Object Model** with reusable test components
- **ThreadLocal** driver management and centralized explicit waits
- Cross-browser and environment-based configuration
- Failure screenshots, logging, and Excel test reports
- Automated scenarios for Login, Admin, PIM, and Users

`Java` `Selenium` `TestNG` `Maven` `Apache POI`
